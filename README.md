# Good Room flyers by Bráulio Amado

An unofficial homage to the flyers [Bráulio Amado](https://badbadbadbad.com/) designed for [Good Room](https://ra.co/clubs/97606), the Brooklyn club, from 2015 to 2026.

**[Open the gallery](https://raw.githack.com/Orn3tte/good-room-flyers/main/index.html)**

This is a fan project, not affiliated with Bráulio Amado or Good Room. The artwork is entirely his. This repository holds no images: the gallery shows each flyer directly from Resident Advisor, where it was first published.

## The gallery

592 flyers, grouped by year. Tap or click a flyer to see it full size, then swipe or use the arrow keys to move through them. Each one links to its event on Resident Advisor. The slider at the top changes the size of the thumbnails.

## Files

| File | What it holds |
| --- | --- |
| `index.html` | The gallery |
| `links/selection.tsv` | The 592 flyers in date order: year, file name and link to the original image on Resident Advisor |
| `links/selection-links.txt` | The same 592 links, one per line |
